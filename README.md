# Quiz Buzz

Quiz Buzz is a browser-based quiz application for competitive exam practice and programming-language interview preparation. The project is a single HTML file with its CSS and JavaScript included.

## Features

- Choose from general knowledge, social studies, science, computer science, and programming-language topics.
- Practice competitive exam question sets and programming interview questions.
- Answer questions in a timed quiz session.
- Review your score, correct and incorrect answers, and percentage when you finish.
- Run locally without installing dependencies or a build tool.

## Run locally

1. Clone or download this repository.
2. Open `quizzbuzz.html` in a modern web browser.
3. Choose a topic and start a quiz.

No package installation or build step is required. The page uses an external image for its hero background, so an internet connection may be needed to display that image.
